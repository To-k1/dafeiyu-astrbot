      使用帮助 · 主人 QQ 与 DSH
    
      
      
      预算与连接
      /额度 查肥鱼亲自执行的人民币账本。/dsh ping 查正式自主和受托 DSH 的连接与模型路线。/go额度 通过控制台已保存的 OpenCode Go Key 查正式任务账户的订阅窗口。
      
      
      步骤与等待时间
      步骤和超时约束当前的聊天或后台回报。任务已入队时，可以继续查原任务和等结果；工具因超时未返回时，以任务回执为准。Go 订阅额度用 /go额度 查。
      
      
      肥鱼自行用 DSH
      平常聊天直接说你想做什么。肥鱼自行决定亲自处理，或用 df_dsh_submit_file 查看已登记素材、整理资料、写草稿或运行受限 Python。短活结果回到对话，长活可在后台完成后回复，编号供肥鱼查进度。探索和创作轮次可用 df_file_research。素材名单在「自主生活与主动联系设置」。
      
      
      主人明确委托
      /委托 sample.csv 请统计 count 列合计、/委托 任务 写一份草稿 或 /委托 代码 用 Python 核验计算。明确委托走正式 Go 后台，并返回可查询和控制的编号。代码入口需启用 Windows Python 执行。
      
      
      查旧任务
      问「用 DSH 任务记录查 BV1g8Wq6DEXj 上次代看的报告，不用重跑」或「查委托 ID，把原报告读给我」。肥鱼用 df_dsh_history，可按 BV、文件名、关键词、任务或经历 ID 查。已完成文件可从原会话读回；公开视频代看保存报告和采样时间，视频本体是临时文件。/委托 列表 可直接看文件任务状态。
      
      
      后台视频和网页
      对耗时的代看或检索，可以让肥鱼后台处理。完成后由她回复，处理中可继续聊天。也可以请她用 df_dsh_public_job 查进度或取消。
      
      
      暂停、恢复、取消
      用 /委托 暂停 ID、/委托 恢复 ID、/委托 取消 ID。运行中以 DSH 的停止回执为准，再用 /委托 列表 核对。
      
      
      查网页和看视频
      直接交代问题或 B 站链接即可，默认走 df_web_search、df_dsh_video。想让肥鱼亲自查或亲自看时直接说明；她也可以自行选择亲自复核。
      
      
      工作区与代码
      AstrBot 的直接文件工具使用自己的工作区。正式 DSH 以 Windows 专用账户访问其已授权的工作目录，可以在 AstrBot 工作区之外读素材、写产物。启用「Windows Python 执行」后可让它在受控 Python 工作区运行代码并交付结果。当前文件预设使用已登记素材；要接入另一目录，需给 DSH 配置该目录和对应 Windows 读写权限。临时在 AstrBot 终端运行的 DSH headless 使用另一份配置。
      
      
      和小弟聊天
      肥鱼可自行用 df_dsh_agents 创建、改名、暂停或归档小弟，用 df_dsh_chat 接续原对话。聊天始终异步，发送立即入队，小弟答完自动交回肥鱼；同一小弟的新消息按顺序处理，无需发短话催取。主人发起的交谈结果走已有 QQ 待发队列，自主交谈先交回肥鱼本人。用 action=get, chat_id=内部ID 可只读查原回复；action=list 查最近状态。查询不会发送新一轮。超时和重启保留原请求，异常会记为待核对，不伪装成成功。
      
      
      角色卡与单人故事
      直接上传 UTF-8 的 .md 或 .txt。角色卡写人格和说话方式，单人故事在「单人故事」里选小弟上传。已保存的文本可分别下载。聊天、任务和长期记忆可在「历史记录迁移」整体转移。
      
      
      按需查看多人故事
      上传多人故事时，可勾选「大肥鱼」和其他参与角色。需要查故事时，肥鱼用 df_story(action="list", query="标题关键词") 找当前分组的标题和参与者，再用 df_story(action="read", story_id="故事 ID") 读指定正文；长篇按 next_offset 分页。普通对话和自主活动不预先加载正文。故事是出厂设定，真实相处的记录另从 LivingMemory 查。
      
      
      他人印象
      在「DSH 小队与任务 → 他人印象」选择大肥鱼或小弟，上传或下载一份 .md 或 .txt。直接在正文里写角色名即可。大肥鱼可按需用 df_story(action="impressions") 读取自己的文件，长篇按 next_offset 分页。
      
      
      同一个小弟的不同聊天
      使用 df_dsh_chat 并指定 agent_id：action=session_new, title=主题 新建并选中；session_list 查看会话及当前选择；session_select, session_id=会话ID 切换或恢复；session_archive, session_id=会话ID 归档。普通发送默认续接入队时选中的聊天，也可明确指定 session_id。归档保留历史和已排队的消息，恢复后可继续。新聊天保留小弟身份与人格；任务、组会仍使用独立会话。保存历史不代表已有跨会话长期记忆。
      
      
      小队的长期记忆与来源
      肥鱼可用 df_dsh_memory 的 sources/source 查原记录，search/get 查长期记忆，save/update/forget 保留、纠正或删除记忆；不确定写入用 reconcile 核对。留空 agent_id 管理肥鱼自己的 LivingMemory，指定小弟则管理其独立记忆。小弟日常聊天、文件任务和组会可检索自己的旧约定，并自行选出值得保留的事实或评价；原文继续留在聊天、任务和会议记录中。小弟的记忆使用独立数据目录，主人私聊记忆不会整库交给小弟。小弟观点、肥鱼评价、系统事件事实分别标明，不能把小弟的偏好记成主人偏好。记忆保存失败不代表聊天未完成，也不应重跑任务。
      
      
      具名派活与组会
      直接告诉肥鱼想请哪位小弟做什么，或请她选几位小弟讨论。她用 df_dsh_guides 管理指南、df_dsh_assign 派活和取回成果、df_dsh_meeting 查看发言、插话、暂停和续会。可以请她按轮数或时间接收组会汇报。
      
      
      小弟再派活
      具名小弟可把授权的文本资料或隔离 Python 交给无名工具，再用回报续做原任务。无名工具可继续拆分同一支线。请肥鱼按子任务 ID 查询、暂停、恢复或取消，其他支线可以继续。原报告可沿父记录回查。
      
      
      指南与身份
      名字、人格和日常对话属于同一位小弟。工作指南按本次任务选择，可以组合和更新；已派任务保留派出时的版本。组会完整发言可继续查询，可请肥鱼插话、暂停、续开或停止。会议讨论中的引用可另派具名任务取证。
      
      
      Windows 桌面操作
      例如「请用 Windows 桌面工具，让潮汐笔记查询可用内存，并启动再正常关闭已登记的个人程序」。工具 df_windows_task 可选择小弟和本次指南。软件需预先登记，支持便携 ZIP 安装、启动和正常关闭；有未保存提示时保留窗口。
      
      
      桌面账户与配对
      FishHomeDesktop 是专用 Windows 标准账户。它的账户密码用于 Windows 登录，控制台「Windows 专用桌面配对」填写该账户服务生成的 broker-token 文件内容。当前已配对的 ThinkBook 可继续使用。
      
      
      仅登录 FishHomeOps 的自动桌面
      在下方加密保存 FishHomeDesktop 标准账户密码，并启用「登录 Ops 后自动启动桌面」。登录 Ops 后，随托盘的「启动全部」启动「Windows 个人桌面」服务，不必另登 Desktop 或开 PowerShell 窗口。服务以 Desktop 账户运行，窗口显示在 Ops 桌面。保持 Ops 解锁；锁屏后 GUI 操作不可用，后台文字、文件等能力按各自服务继续运行。退出托盘前可单独停止此服务；有未关闭的个人程序时会保留窗口并提示处理。
      
      
      旧版桌面启动与切换
      旧方式仍可手动登录 FishHomeDesktop 并运行 powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:ProgramData\FishHomeDesktop\Start-DesktopBroker.ps1" -Python "$env:ProgramData\FishHomeDesktop\python\python.exe"。两种方式共用端口，先关闭已打开的个人程序并停止旧服务，再切换。若端口上的服务属于另一登录会话，不应把它当作 Ops 自动桌面。首次升级受保护组件时运行项目的 deploy\dsh_bridge\Update-DesktopBroker.ps1 -InstallRoot 安装根目录，Windows 会要求管理员权限。
      
      
      完整读取文本
      工具结果正文不再因整理聊天历史而被裁剪，DSH 文件读取自动接续到末页。AstrBot 自带文件工具超过单次大小限制时仍会明确提示分段；可让肥鱼继续读取余下部分。已经折叠过的旧聊天历史不会自动复原，需要重新读取原文件。
      
      
      手动同步代码
      台式机在公开 fish-home 分支提交并推送代码；向 ThinkBook 传送 git archive 生成的代码包后，还需在停止相关服务时安装到已启用插件目录，再启动服务。ThinkBook 当前是解压安装，不能只运行 git pull 就宣称插件已更新。完整步骤见项目 docs/CODE_SYNC.md。配置同步、代码更新、状态备份分别操作；正式数据库以 ThinkBook 为准。
      
      
      实时看组会
      首页会自动显示进行中的会议。「组会会场」可在独立标签页打开，DSH 侧栏也能进入同一会场。点击发送会把你的原话署名为「主人」，接到下一条尚未开始的发言。茶会和闲聊指同一种会议。
      
      
      QQ 文件
      在主人私聊发文件时附上处理要求。肥鱼可将已可获取的附件复制进 shared/qq-inbox，再交给 DSH。若 QQ 仍要求接收，可完成接收后重发文件。
      
      
      QQ ZIP 取材
      在当前私聊发送 ZIP，并说明要查看哪些内容。肥鱼用 df_dsh_shared 收取后，可用 zip_list 列清单、zip_read 分页读 UTF-8 文本，或用 zip_extract 把选中的条目复制到新的 shared/qq-zip 任务目录，再把返回的路径交给 DSH。原附件保留，新会话需要重新发附件；长期归档或覆盖资料时另行确认。
      
      
      共同语言提示词
      可以启停或上传 UTF-8 的 TXT、MD。保存后，肥鱼和具名小弟的新请求会读取现行设置。原人格卡继续使用。
      
      
      安全插件
      cc-safety-net ↗ 可在 DSH 执行前拦截部分危险命令和敏感读取。Windows 账户权限和执行预设决定实际可达范围。正式服务加载该插件的状态待验证。
      
      
      原版 Bridge 提示
      AstrBot 配置页中旧版 dsh_ask、dsh_ping、/dsh scan 的追加文本是原版默认。FishHome 通过上面的正式工具接线，不读取该旧文本。
      
      
      提醒
      /提醒 YYYY-MM-DD HH:MM 内容，时间用北京时间。用 /提醒 列表 或 /提醒 取消 ID 管理。
      
      
      QQ 掉线与待发消息
      已经生成的主人私聊回复、到点提醒和委托回报会持久排队。QQ 在线且连接恢复后按顺序错峰发送，默认待发有效期 24 小时。发前可取消排队中的提醒。取得 OneBot 消息 ID 才标记已受理；发送结果不确定时保留待核对状态。主动联系继续检查暂停、额度和冷却，旧主动消息随原联系安排结束。
      
      
      主动联系
      今天别找我 暂停到当天结束。先不要主动聊天 暂停到你发 恢复主动联系。已接受的委托和提醒照常交付。
      
      
      自主活动
      暂停自主活动 或 恢复自主活动。也可以问「你最近一次生活安排是什么？计划和实际结果分开说」或「查一下你自己发起的 DSH 文件任务」。后者查已有成果。
      
      
      长项目与工坊
      模块开启后，可以问「你现在有哪些长期项目？」或「你在创作工坊里有哪些草稿？」。需要查原始来源时，可以请她检索已有活动记录。
      
      
      语音与截图
      肥鱼可自行选择语音回你，也可以直接说「只用语音回答」或「这轮只用文字」。截图看看 获取手机画面。
      
      
      B 站与会话
      /bili互动 状态 查 B 站互动额度和审批。/new 开新对话，/sid 查当前会话来源。
