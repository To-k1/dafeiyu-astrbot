# DSH v3.1 增量设计与权限边界

## 本阶段接入

- ThinkBook 的 `D:\FishHome\workspaces\shared` 由 FishHomeOps 和标准账户 FishHomeRunner 共用。`dsh\life`、`dsh\commission` 保存对应项目和成果。DSH 的 profile、登录和密钥仍在原运行目录。
- AstrBot 通过 owner-scope 的 `df_dsh_shared` 直接读写共享文本。DSH 会话可从共享目录运行已批准的文件预设。历史报告按记录里的原始 Session 回读，迁移时不改历史里的绝对路径。
- QQ 私聊的当前消息有可下载附件时，肥鱼可以要求将 AstrBot 收到的文件复制到 `shared/qq-inbox`，返回消息来源和相对路径。附件原名是数据，取件由受控会话身份决定。
- 纯文本回合使用单独的无工具预设。它使用 DSH 原生 Session 和 Go 回执。具名聊天记录稳定身份和原生 Session，模型实际接到当前人格版本。无名字时保留单次默认入口。
- 文件委托继续使用现有持久化记录。后台完成结果先交给主人会话的 Agent，确认 Agent 生成内容后保存交付状态。交互生成走已配置的本机交互网关。
- 主人私聊的长搜索和代看可通过工具的 `background=true` 立即入队。AstrBot 保存用户作用域、原消息和任务 ID；控制台在独立进程持久化队列、原生 Session 回执和报告。短任务的同步入口保持原超时。`df_dsh_public_job` 查看或取消这条后台任务，也可在控制台取消。完成结果以 DSH 代办来源入经历记录，再进入同一回复通道。
- 任务标识在 AstrBot 与控制台之间绑定。同一 ID 重复提交返回原任务。AstrBot 重启后按该 ID 读旧状态，控制台进程重启后恢复排队任务，把已启动但无终态的任务标为待核对。取消已派未开始任务会留下记录，迟到的同 ID 请求不会执行。

## 余下设计

- 现有名册保存稳定 `agent_id`、肥鱼选定的名字、人设版本和日常会话引用。指南及项目会话还需独立接入。具名重任务单独建会话并引用同一小弟身份，按任务取指定材料。
- 组会通过各个小弟的真实调用保存发言与证据。肥鱼设定按轮数或时间检查进度，只有有实质变化才汇报。结束及需要她处理的阻塞进入她的队列。
- 并发工作按共享资源约束，测试视频和搜索运行有真实重叠。QQ 节奏在出站层按会话排序并持久化，以发送回执区分成功、拒绝和不确定。
- 原生 DSH 的审批策略仅有 `ask` 和 `never`，后者表示拒绝询问所覆盖的操作。日常工作走下方无需逐次确认的受控工具。原生 Shell 请求扩大执行权限时，继续通过人工审批。Windows 普通账户权限继续保护核心配置和其他账户。

本机已安装 SDK 的 `approval/request` 提供 session、toolName、callId 和 reason。工具参数须用 callId 关联同一 Session 的实际调用。Web 的答复客户端还需独立的交互能力，通过受认证的 loopback Remote 连接。普通文本、共享文件和合成 QQ 取件当前无需启用该答复客户端。

### 受限项目操作

- 已有 Compute 服务通过鉴权的本机 MCP 提供项目操作，真实工程目录为 `D:\FishHome\workspaces\dsh\projects\项目名`。Windows AppContainer 执行 Python、项目测试或离线 PowerShell。PowerShell 通过进程内的 `FishProject:\` 盘定位到隔离项目副本，脚本可使用相对路径。成功后只发布调用中明确列出的输出。运行期间有其他进程修改同一产物时，保留其修改。
- 项目可通过受控工具准备 PyPI 预编译 wheel。下载阶段只准备包，安装和导入在隔离副本内执行。下载缓存继承实际项目 ACL，pip 临时目录在 AppContainer 的项目副本内。单文件清理按精确相对路径执行。
- 上述工具处在已批准范围，调用无需弹出通用 DSH 审批。任意 Shell、源码包构建和系统级安装的处理仍有独立的执行边界。工作区、人格和桌面守护进程的权限互不传递。

### 专用桌面个人程序

可以在管理员维护的 `%ProgramData%\FishHomeDesktop\personal-apps.json` 登记软件，例如 `{"editor":"editor/editor.exe"}`，实际文件放在该标准账户的 `%LOCALAPPDATA%\FishHome\desktop\apps`。管理员用 `Prepare-DesktopBroker.ps1` 准备组件，专用标准账户登录桌面后用 `Start-DesktopBroker.ps1` 启动，再在控制台完成配对。桌面任务可以调用 `windows_apps` 查看、启动和请求正常关闭。关闭只针对本次 broker 启动且进程及窗口都匹配的程序，收到提示框或进程仍在运行时保留窗口。

若需要肥鱼自行安装，可登记 `{"editor":{"executable":"editor/bin/editor.exe","archive":"editor.zip"}}`，由管理员把 ZIP 放在 `%ProgramData%\FishHomeDesktop\packages`。ZIP 内路径相对软件目录，例如 `bin/editor.exe`。标准账户可用 `windows_apps install` 安装已登记包，安装和启动分别执行，已有程序目录保留。
