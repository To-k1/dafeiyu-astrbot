# ThinkBook DSH 现状与故障链路

2026-11-17，正式 ThinkBook，AstrBot 4.29.4，DeepSeek Harness 0.2.2-rc.1，NapCat 4.18.38。DSH 的 59934 自主和 59935 受托进程均通过回环接入 OpenCode Go。

| 项目 | 证据和结论 |
| --- | --- |
| 旧测试单 `97bd04b259f7` | 现场已实测。带 `sample.csv`、使用计算预设、未生成报告。原记录为 `needs_review`，但 DSH 会话仍运行且有待审批。用户授权后只取消该回合，回读 `aborted`，保留原 QQ 投递状态及 10 笔 Go 回执。 |
| 旧单 `a7588bf7066a`、`bbf8c8f116b2` | 现场已实测。两笔无附件，正文为空，没有保留 Session ID 或产物。变更前受托配置缺 `fishhome-draft`，是与故障阶段吻合的解释，原始异常未能复原。两笔原记录保留。 |
| 旧工作区 | 现场已实测。FishHomeOps 无法 stat Runner 账户中的自主和受托目录。旧共享目录位于 AstrBot 所有者会话下面。两者曾是独立目录，即使出现同名文件也不代表两边会发现它。 |
| 正式 D 盘工作区 | 已切换并实测。见 [验收记录](03_变更与逐项验收.md)。显式路径、目录枚举和模型是否实际读取分别验证。旧工作区保留给既有 Session 回读。 |
| 搜索/代看并发 | 旧 [VideoWorker](../../deploy/desktop_manager/video_worker.py) 的搜索、代看、桌面共同使用一个锁。现已上线两路资源池，隔离验收观察到真实视频与搜索重叠运行。进程结束仍清理其临时目录，媒体任务的持久排队和重启恢复待接。 |
| QQ 附件来源 | 本机安装源码确认 AstrBot 的 OneBot 适配器在私聊文件段调用 NapCat `get_private_file_url`，构造 `File`。真实 QQ 附件是否进入这一分支仍待用户实测。在 FishHomeOps 的常见 Documents 路径和 NapCat 安装目录下未找到现成的 `FileRecv`。 |
